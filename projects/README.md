# Проекты

Каждый проект — отдельная папка. Всё, что в ней лежит, индексируется в базу:
режется на фрагменты, векторизуется и становится доступно поиску.

## Как завести новый проект

```
mkdir -p ~/projects/ai-farm/projects/имя-проекта
cp ~/projects/ai-farm/projects/_template/project.toml ~/projects/ai-farm/projects/имя-проекта/
# положить файлы проекта в ту же папку
~/projects/ai-farm/.venv/bin/python -m rag.ingest имя-проекта
```

## Если проект уже лежит в другом месте

Не нужно ничего копировать — достаточно указать путь в `project.toml`:

```toml
[project]
name = "rdp-mcp"
path = "~/rdp-mcp"
category = "automation"
```

Папка-обёртка при этом остаётся, но она пустая: индексатор пойдёт по `path`.

## Поля project.toml

| поле          | обязательное | смысл                                              |
|---------------|--------------|----------------------------------------------------|
| `name`        | нет          | имя в базе; по умолчанию — имя папки               |
| `path`        | нет          | каталог с файлами; по умолчанию — сама папка        |
| `category`    | нет          | метка для фильтрации поиска                          |
| `description` | нет          | пояснение в одну строку                              |
| `exclude`     | нет          | список шаблонов «что не индексировать»               |

## Что не индексируется

Служебные каталоги (`.git`, `.venv`, `node_modules`, `__pycache__`, `build`,
`dist`, `target` и подобные), бинарные файлы, файлы без расширения (кроме
`Dockerfile`, `Makefile`, `requirements.txt` и ещё нескольких) и всё, что
больше 5 МБ. Порог меняется ключом `--max-file`.

Своё добавляется ключом `exclude` — шаблоны в стиле `.gitignore`, сравнение
идёт с путём от корня проекта:

```toml
exclude = ["decoded", "dumps/*.csv", "src/taxi-app.html"]
```

Заведено 20.09.2026 для `lime-taxi-app`: там лежал распакованный APK (7373
файла smali, 73 МБ), а собранные одним файлом страницы дали бы 12 000
фрагментов против 400 у всего остального проекта. Полезно помнить: **каталог с
именем `build` пропускается жёстко**, поэтому исходники в нём в поиск не
попадут — их лучше держать в `src/`.

## Повторная индексация

Запускать ту же команду повторно безопасно и дёшево: у каждого файла хранится
sha256, и неизменившиеся файлы пропускаются, не доходя до модели. Полный
пересбор — `--force`. Предпросмотр без записи в базу — `--dry-run`.
